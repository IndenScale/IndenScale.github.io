## IndenScale 个人主页

基于 Next.js + Tailwind CSS。

## 开发

```bash
npm run dev      # 启动开发服务器 (port 3456)
npm run build    # 构建静态站点
```

内容目录：
- `content/eac/` — Engineering as Code
- `content/architecture/` — Agent 架构
- `content/knowledge/` — 运营工业化

## RSS 订阅

构建后 RSS 文件位于 `dist/eac/feed.xml`，部署后可通过 `/eac/feed.xml` 访问。
